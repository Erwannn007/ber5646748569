# BERSERKER — Les Donjons de Sang

FPS rétro façon Doom, dark fantasy, à l'épée géante. Tout (moteur, pixel art, sons) est généré par le code : aucun asset externe.

**Jouer :** ouvrir `index.html` (ou la GitHub Page du repo).

- ZQSD / WASD : bouger — souris : viser (molette : sensibilité)
- Clic gauche : combo 3 coups — clic droit maintenu : coup chargé circulaire
- Espace : esquive — R : Fureur — M : carte
- Affaiblis un monstre : quand il clignote, frappe-le pour une **exécution**
- Tue tout pour ouvrir la porte de sang et descendre

Sur iPhone : "Partager → Sur l'écran d'accueil" pour le plein écran, en paysage.
